# Java Fundamentals & Practical Projects

A structured repository consolidating academic coursework and practical projects covering core Java programming concepts, object-oriented design, algorithmic foundations, file I/O, and console application architecture.

---

## 📂 Repository Structure

| Module | Topic | Description |
| :--- | :--- | :--- |
| [`02-data-types`](./02-data-types) | **Primitive Types & Operations** | Variable declarations, primitive types, type casting, basic operations. |
| [`03-formatting`](./03-formatting) | **String Formatting & I/O** | Console formatting, `printf` specifiers, alignment, precision. |
| [`04-cycles`](./04-cycles) | **Control Flow & Loops** | `for`, `while`, `do-while` loops, number sequence generation, iterative text processing. |
| [`05-math-functions`](./05-math-functions) | **Math & Functions** | Mathematical functions, algorithmic problem solving, formula computations. |
| [`06-arrays`](./06-arrays) | **1D Arrays & Algorithms** | Array manipulation, search, sorting algorithms, sequence monotonicity checks. |
| [`07-2d-arrays`](./07-2d-arrays) | **Matrices & 2D Arrays** | Matrix initialization, transformations, diagonal scans, condition evaluations. |
| [`08-reversal-functions`](./08-reversal-functions) | **Functions & Reversals** | Modular method design, string/array reversal algorithms. |
| [`09-tic-tac-toe`](./09-tic-tac-toe) | **Console Tic-Tac-Toe** | Interactive console game: board state representation, turn alternation, win validation. |
| [`10-auth-system`](./10-auth-system) | **Authentication System** | Console user authentication, credential validation, interactive registration flow. |
| [`11-file-io`](./11-file-io) | **File I/O Streams** | File reading, writing, byte/character streams, persistence handling. |
| [`13-date-time`](./13-date-time) | **Date & Time API** | Modern `java.time` package usage, date arithmetic, modular packages (`logic`, `utils`). |
| [`15-tic-tac-toe-persistence`](./15-tic-tac-toe-persistence) | **OOP Tic-Tac-Toe with Saves** | Full OOP game: separated components (`GameBoard`, `GameStats`, `GameSettings`, `Saves`), persistent storage. |

---

- **Language:** Java (JDK 17+)
- **IDE / Tooling:** IntelliJ IDEA
- **Paradigms:** Procedural programming, Object-Oriented Programming (OOP), Modular Design
